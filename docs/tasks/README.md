# Task specs T01–T20 (historical)

These numbered specs drove the initial build-out and are kept as a design
record — including the retro-annotations noting bugs found during
implementation. They are **not** the current scope: work after T20 (T21+ is
referenced by number in some docs) is tracked in GitHub issues instead of
task files. When a task spec and a spec doc in `docs/` disagree, the spec
doc wins.
