# Restic Station app icon source

The checked-in `AppIconSource.png` was generated with OpenAI image generation from this production prompt:

> Create a polished 1024×1024 macOS app icon for a native backup-management utility named Restic Station. Center a compact secure archive of three layered data blocks inside one clean circular restore arrow, with subtle station-canopy geometry. Use premium Apple-platform icon styling, crisp dimensional vector-like geometry, deep navy, cyan/teal, and a restrained warm amber accent. Keep it legible at 16 px and all important content within the central 80 percent. No text, letters, numbers, third-party logos, watermarks, screenshots, devices, people, trains, literal railway imagery, transparency, glass, or thin details.

Run `./App/Resources/generate-app-icon.sh` from the repository root after replacing the source. The script creates every raster size referenced by the asset catalog.
